# MediaStationGo Windows v1.0.9

修复 v1.0.8 公共包缺少原生视频桥接 DLL 的问题。受影响时，组件管理会显示
“Native video bridge is missing from the application directory”，RTX Video 超分、
NVIDIA VFG 插帧和 DLSSNR 无法使用。

## 修复

- 主程序重新携带 `video_enhancement.dll`（视频增强桥，ABI 5）和 `nvngx.dll`
  （DLSSNR 适配器），随安装版与便携版一起分发。
- 构建和公共包校验新增必检项：缺少任一桥接 DLL 时直接失败，不再产出功能不完整的包。
- 四个组件保持独立 prerelease 分发：RIFE 插帧、RTX Video 超分、DLSSNR（实验）、
  NVIDIA VFG 插帧；组件安装后仍需退出所有实例并重新启动。

## 升级说明

- 从 v1.0.8 升级即可恢复视频增强组件；已安装的组件不需要重新下载。
- 若组件页面仍提示桥接缺失，请确认运行的是 v1.0.9 的安装目录或便携包，而不是旧目录中的
  可执行文件。

## 下载与升级

- `MediaStationGo-1.0.9-windows-x64-setup.exe`：当前用户安装版。
- `MediaStationGo-1.0.9-windows-x64-portable.zip`：完整解压后运行的便携版。
- `MediaStationGo-1.0.9-windows-x64-source.zip`：对应候选提交的完整源码包。
- `SHA256SUMS.txt`：上述三个包的 SHA-256 校验值。

安装版和便携版均支持在“设置 → 更新”中检查、下载并应用新版本。

## 验证边界

- 本轮验证覆盖公共包暂存后的桥接 DLL 存在性、哈希和应用启动；未重新执行各组件的 GPU
  实机播放测试。
- 桥接 DLL 由项目源码针对 NVIDIA RTX Video SDK 构建，来源与重建方法记录在
  `resources/win/video-bridge/README.md`。
