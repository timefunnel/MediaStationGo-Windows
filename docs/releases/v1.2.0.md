# MediaStationGo Windows v1.2.0

本版本汇集 v1.1.0 之后的 11 项开发提交，新增首页加载骨架、详情与选集展示、HDR10+ / Dolby Vision 画面增强，并修复云播放停流取消、换集状态和应用更新进度等问题。

## 新增功能

- **首页加载骨架**：放大首页轮播横幅，媒体数据与横幅图片加载期间分别展示加载状态；加载失败显示明确反馈，不将未加载的内容当作已完成。
- **新版作品详情**：电影详情集中展示海报、简介、观看进度和播放操作，片源参数按需展开；剧集与连载动漫提供缩略图和集数两种选集视图，长季按组展示，并定位到当前续播集。
- **HDR10+ / Dolby Vision 画面增强**：配套更新 FFmpeg、mpv、libplacebo 和原生视频桥，保留逐帧动态元数据；支持 Dolby Vision RPU 映射与 Profile 7 FEL 增强层重建，再接入兼容的 NR、VSR、VFG 增强链。必要增强层缺失或处理失败会明确报错，不静默丢弃增强层。
- **应用更新进度**：校验和应用更新期间在确认窗口内显示状态，便携版更新助手增加独立进度窗口，覆盖等待主程序退出、文件替换和重启阶段。

## 功能调整

- **剧集详情布局**：简化头部信息，移除剧集参数展开区；封面和单集缩略图保留对应集的分辨率角标，选集显式请求所需媒体信息，不借用其他集参数。
- **选集交互**：缩略图每页四集，翻页采用双向横向滑动；集数视图每组最多五十集，单季超过三十六集默认使用集数视图。选集区域与详情页统一滚动，演职员默认展开并支持手动收起；启用减少动态效果时直接翻页。
- **主题切换**：标题栏与页面圆形主题过渡同步，避免切换时出现颜色不同步。
- **云播放启动**：减少重复请求，复用已校验的最多 64 KiB 文件头；初始选轨与续播定位交给加载流程处理，视频就绪要求实际已有可显示帧，不将这些调整等同于所有片源的固定提速幅度。

## 问题修复

- **停流后的停止与退出卡死**：自定义媒体流在等待响应头或正文时检查取消；停止、换片和退出后终止旧读取，不再追加旧流请求。正常读取设有明确的无数据等待边界，恢复失败保留结构化错误，不误报自然播放结束。
- **换集状态串扰**：隔离前后剧集的播放状态，避免上一集的迟到事件影响新一集的加载与播放控制。
- **播放控制层唤起**：修复控制层显示与交互状态，保持鼠标和键盘操作一致。
- **更新过程无反馈**：应用更新期间持续显示进度，并避免重复确认或提前关闭正在执行的更新对话框；失败保留可见错误。
- **Windows 构建路径**：使用 CMake 短中间路径机制，从真实仓库路径完成 CEF 构建，不再依赖虚拟盘符；CI 固定使用符合要求的 CMake 版本。

## 下载与升级

- `MediaStationGo-1.2.0-windows-x64-setup.exe`：当前用户安装版。
- `MediaStationGo-1.2.0-windows-x64-portable.zip`：完整解压后运行的便携版。
- `MediaStationGo-1.2.0-windows-x64-source.zip`：与发布候选提交对应的完整源码包。
- `SHA256SUMS.txt`：上述三个包的 SHA-256 校验值。

安装版和便携版均支持在“设置 → 更新”中检查、下载并应用新版本。本次仅通过 GitHub Releases 分发，不启用旧 CDN。已有可选增强组件继续复用，无需为本次主程序升级重复下载；普通播放不要求 NVIDIA 显卡或安装 NVIDIA 增强组件。

## 验证与限制

发布前执行相关 Rust 单测、离线浏览器界面回归与候选包检查。云播放读取、取消和错误传播使用本地 loopback 测试，不以生产媒体或真实云盘作批量探测。

HDR10+ / Dolby Vision 的既有 GPU、合成短片及短时实片验证范围见[视频组件记录](https://github.com/timefunnel/MediaStationGo-Windows/blob/v1.2.0/docs/windows-video-components.md)。本次不宣称新增 Dolby Vision HDMI 位流直通、12 位输出、跨 GPU 验收或所有 4K 长片的实时性能保证；增强功能仍需兼容的 GPU、驱动与可选组件。详情页说明见[作品详情页第二版](https://github.com/timefunnel/MediaStationGo-Windows/blob/v1.2.0/docs/detail-page-v2.md)，播放修复证据见[播放诊断记录](https://github.com/timefunnel/MediaStationGo-Windows/blob/v1.2.0/docs/windows-playback-diagnostics.md)。
