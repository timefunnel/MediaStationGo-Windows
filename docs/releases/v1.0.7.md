# MediaStationGo Windows v1.0.7

本版本新增播放弹幕，并将 RTX 插帧拆分为按需安装的独立组件。

## 新增功能

- **播放弹幕**：从服务端的 Emby 弹幕接口获取已匹配内容，按当前播放位置绘制滚动、顶部和底部弹幕。暂停、拖动进度、换集和退出播放时同步更新或清除，不占用字幕轨，可与字幕同时显示。
- **弹幕开关**：在“设置 → 播放与字幕”控制是否显示弹幕，关闭后立即清除当前画面的弹幕，选择会保存并用于后续播放。弹幕内容需要服务端接口支持。
- **RTX 插帧组件管理**：在“设置 → 播放与字幕”按需下载、安装或卸载独立组件；安装、卸载均需退出所有应用实例后重新启动生效。支持下载进度、当前下载源、断点续传和待安装任务取消。

## 功能调整

- **主程序不再捆绑插帧组件**：普通播放无需下载 NVIDIA 运行时与 RIFE 模型。需要插帧时单独安装组件；三档模型、严格 2 倍插帧、原生播放算法与 profile 合同保持不变。
- **自有 Engine 构建助手**：独立组件使用项目自有助手生成当前显卡对应的 Engine，不再分发 NVIDIA SDK 命令行工具。
- **组件校验**：整个下载包通过 GitHub 发布的 SHA-256 校验，安装时继续核对组件版本、平台、原生 ABI、精确文件集合以及每个文件的大小和 SHA-256。

## 问题修复

- 修复 mpv 弹幕命令参数格式错误导致叠加层被拒绝的问题。
- 修复待安装文件损坏后无法取消、重新安装的问题；取消仅作用于待安装任务，不删除已激活组件。
- 修复组件状态查询暂时失败后任务跟踪中断的问题；重新查询不会重复发起安装。
- 修复组件操作中断后遗留暂存目录的问题；仅回收可确认归属且通过路径检查的目录，未知文件保留并显式报告异常。

## 下载与升级

构建流程同步修复了 libplacebo 源码下载被上游反机器人验证拦截的问题：改用[项目官方 GitHub 镜像](https://github.com/haasn/libplacebo)，提交和源码包 SHA-256 保持一致。CEF、FFmpeg、其他原生依赖和 Cargo 缓存在各自步骤成功后立即保存，避免后续打包失败时丢失已完成的构建缓存。

- `MediaStationGo-1.0.7-windows-x64-setup.exe`：当前用户安装版。
- `MediaStationGo-1.0.7-windows-x64-portable.zip`：完整解压后运行的便携版。
- `MediaStationGo-1.0.7-windows-x64-source.zip`：对应候选提交的完整源码包。
- `SHA256SUMS.txt`：上述三个包的 SHA-256 校验值。

安装版和便携版均支持在“设置 → 更新”中检查、下载并应用新版本，继续通过 GitHub Releases 发布。

从旧版升级后，若需继续使用 RTX 插帧，请先在设置中安装独立组件并重启。组件在单独的 [RTX 插帧组件 Release](https://github.com/timefunnel/MediaStationGo-Windows/releases/tag/rife-component-x64-v1) 发布；其 prerelease 标记用于区分组件与主程序版本，不参与主程序更新检测。安装组件仍需要兼容的 NVIDIA RTX 显卡与驱动，其他设备的普通播放不受影响。

本次未改动插帧模型与算法，也不宣称已解决此前仍在排查的质量档 HDR10 偶发画面问题。
