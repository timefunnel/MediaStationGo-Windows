# MediaStationGo Windows v1.0.8

本版本把弹幕获取移入播放器，加入 NVIDIA VFG、RTX Video 与 DLSSNR 组件管理，并合并了 v1.0.7 发布线的构建与发布修复。

## 新增功能

- **播放器本地弹幕**：播放器直接搜索腾讯视频、爱奇艺、优酷，下载、缓存、清洗并绘制弹幕，不再由服务端集中代理内容。切换集数、关闭弹幕或退出播放会取消旧请求，源站失败会明确提示，不用空结果掩盖。
- **弹幕节目匹配与偏移**：自动按作品信息匹配；匹配不到时可展开“更换弹幕源或节目”，按名称搜索并点选节目与集数，保存 ±600 秒偏移。当前节目可直接调整偏移，无需重新搜索。
- **跨设备同步（可选）**：开启后在同一账号的设备间共享源、节目页面引用与偏移；关闭时按账号与物理媒体版本保存在本机，重启后仍可复用。需要服务端声明 `danmaku-associations` v1；服务端不支持时只影响同步，不影响本地弹幕。
- **视频增强组件管理**：新增 NVIDIA VFG 插帧、RTX Video 超分和 DLSSNR 画面增强的检测、安装、卸载与重启流程，与 RIFE 插帧统一放在“组件管理”页面；安装、卸载在重启后生效。
- **HDR10 / HLG**：原生视频增强路径保留 HDR10 与 HLG 元数据，避免增强后丢失动态范围标记。

## 功能改进

- 播放控制与设置持久化统一，暂停、缓冲、菜单和键盘操作保持控件可用；关闭播放器后再次打开可恢复增强设置。
- 字幕在播放前和重载后正确恢复；修复 TrueHD 单子流环绕声解码。
- 修复部分封面图片重定向后无法加载、继续观看排序不准确、标题栏主题不同步，以及更新后重复进入设置向导。
- 弹幕流畅度保留三缓冲交换链、CEF 回调内纹理复制和 Canvas 正常合成；本机 152 Hz 实测窗口与全屏均约 151.8 FPS，P99 8.0–8.8 ms。
- 界面完成现代影院布局核验，更新侧栏品牌排版、应用图标和窗口图标。

## 兼容性与服务端

- 旧集中弹幕接口已退役。配套服务端为 `074d6a6` 或兼容版本，生产环境已发布；使用旧服务端时本地弹幕仍可用，仅跨设备同步不可用。
- 不再保留第三方播放器的专用弹幕适配。
- 本地源模块随播放器打包，无需安装 Node.js 或额外服务。

## 下载与升级

- `MediaStationGo-1.0.8-windows-x64-setup.exe`：当前用户安装版。
- `MediaStationGo-1.0.8-windows-x64-portable.zip`：完整解压后运行的便携版。
- `MediaStationGo-1.0.8-windows-x64-source.zip`：对应候选提交的完整源码包。
- `SHA256SUMS.txt`：上述三个包的 SHA-256 校验值。

安装版和便携版均支持在“设置 → 更新”中检查、下载并应用新版本。RTX 插帧组件继续在独立的 [RTX 插帧组件 Release](https://github.com/timefunnel/MediaStationGo-Windows/releases/tag/rife-component-x64-v1) 分发，不参与主程序更新检测。

## 验证边界

- 本地源已接入腾讯视频、爱奇艺、优酷，但本次只对腾讯源执行了真实搜索与弹幕下载验证；爱奇艺、优酷未做真实源站验证。
- 跨设备同步的接口、账号隔离、物理版本隔离与冲突控制已验证，但双设备实播未验证。
- 弹幕帧率是桌面采集条件下的合成负载测试，不是光学上屏测量，也不代表具体剧集的播放效果。
