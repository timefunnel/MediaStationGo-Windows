# MediaStationGo Windows v1.1.0

本版本汇集 v1.0.9 之后的 8 项本地提交，重点修复首页启动和滚动迟滞、VFG 原始帧回退，以及播放控制、主题切换和更新确认体验。

## 新增功能

- **主题切换动效**：主题按钮采用居中的太阳 / 月亮图标，切换时从按钮中心展开圆形过渡。开启“减少动态效果”时直接切换主题。

## 功能调整

- **视频增强参数菜单**：改为与应用主题一致的页内菜单，支持鼠标与键盘操作，避免原生下拉菜单的等待和风格割裂；确认参数已生效且播放恢复后，自动收起二级面板，失败时保留错误信息。
- **VFG 输出选项**：统一为“刷新率自适应、2 倍、3 倍”。旧版保存的 4–8 倍设置会明确提示并迁移为 3 倍，其余增强参数保留。
- **播放控制层**：移除多余的“更多”菜单，整理常用按钮，更新弹幕开关及设置图标，并统一账号头像配色。
- **弹幕提示**：自动获取弹幕不再显示过程性提示，手动操作仍提供反馈；错误和弹幕面板状态继续明确显示。
- **更新确认**：下载完成后通过独立模态窗口确认应用更新，支持取消与焦点恢复，避免确认区在设置页底部被遮挡。

## 问题修复

- **首页启动黑屏**：账号恢复和服务端能力查询移出浏览器创建的同步流程，网络等待期间仍可展示界面；失败会明确提示，不反复恢复账号。
- **启动后十余秒滚动迟滞**：修复首次尺寸变化在单调时钟起点未设置结束预算，导致高频重绘持续运行的问题；正常结束初始化重绘并恢复屏幕刷新节奏。
- **首页滚动与刷新**：移除阻塞原生滚动的监听，批量计算卡片行布局；后台快照内容不变时保留现有页面，有变化时继续刷新并恢复滚动和焦点。
- **VFG 画面回退**：原始帧输出改为复制该帧对保留的稳定纹理，避免读取被上游复用的像素；同时修复新帧对绑定与镜头切换状态，保留音频速度、时间线及既有同步规则。
- **播放面板响应**：原生诊断在后台执行，面板立即打开；关闭、切换、退出或重新打开后，旧请求不得覆盖当前状态。
- **组件重启按钮**：待安装或卸载需要重启时，重启操作不再被“组件已安装”的按钮状态阻止。

## 下载与升级

- `MediaStationGo-1.1.0-windows-x64-setup.exe`：当前用户安装版。
- `MediaStationGo-1.1.0-windows-x64-portable.zip`：完整解压后运行的便携版。
- `MediaStationGo-1.1.0-windows-x64-source.zip`：对应候选提交的完整源码包。
- `SHA256SUMS.txt`：上述三个包的 SHA-256 校验值。

安装版和便携版均支持在“设置 → 更新”中检查、下载并应用新版本。已有视频增强组件继续复用，无需重新下载；组件安装或卸载仍需退出所有应用实例并重启。普通播放不要求安装 NVIDIA 组件。

## 验证与限制

本次发布包含离线界面回归、相关 Rust 单测及候选包校验。已有 RTX 5070 Ti / 152 Hz 的 VFG 像素与菜单验证记录见[视频组件说明](https://github.com/timefunnel/MediaStationGo-Windows/blob/v1.1.0/docs/windows-video-components.md)，首页验证见[启动与滚动修复记录](https://github.com/timefunnel/MediaStationGo-Windows/blob/v1.1.0/docs/windows-home-startup.md)。这些记录不代表跨 GPU、所有真实影片或长时间音画同步验收，回调帧率也不等于物理上屏帧率。
