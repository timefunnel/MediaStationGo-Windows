# MediaStationGo Windows v1.2.1

本版本汇集 v1.2.0 之后的 6 项开发提交，重点改善首页推荐与横幅加载、标准 Emby 播放启动，并修复新增服务器登录、后台恢复后的窗口尺寸及剪贴板读取问题。

## 功能调整与性能优化

- **首页随机推荐**：按账号与服务器隔离缓存推荐结果，有效期为六小时；刷新期间保留已有内容，更新失败保留原推荐并记录错误，下一次启动仍可重试。
- **首页横幅与首屏布局**：调整横幅和继续观看区域，让近期入库位于其后；元数据刷新和窗口尺寸变化时保留当前横幅，减少不必要的图片重载与布局跳动。
- **首页加载速度**：减少重复目录查询，在有界并发内加载首页数据，优先获取首张清晰横幅并移除固定启动等待；不通过降低图片分辨率换取速度。
- **标准 Emby 播放启动**：将已经校验的首次 HTTP 响应直接交给播放器读取，避免预检后重新请求同一媒体。保留来源校验、跨源凭据隔离、代理设置、Range 检查、取消和有限恢复机制；启动日志补充容器准备、加载与首帧阶段的耗时。

## 问题修复

- **新增服务器登录与连接设置**：恢复已有账号状态下添加另一服务器的登录入口，修复服务器地址和兼容身份等连接设置的保存、校验与页面交互。
- **搜索结果混入单集**：搜索按作品类型获取结果，排除单独的 Episode 条目，保留电影、剧集等作品入口。
- **后台恢复后页面缩在左上角**：CEF 视口和输入坐标统一读取原生窗口客户区与 DPI，不再依赖可能迟到的 mpv OSD 尺寸缓存；尺寸、DPI、位置及焦点恢复时同步更新，最小化时不生成零尺寸。
- **剪贴板读取越界**：修正 Windows UTF-16 转 UTF-8 时的缓冲区分配，正确处理结尾 NUL，避免粘贴服务器地址或中文账号等文本时发生缓冲区越界。

## 下载与升级

- `MediaStationGo-1.2.1-windows-x64-setup.exe`：当前用户安装版。
- `MediaStationGo-1.2.1-windows-x64-portable.zip`：完整解压后运行的便携版。
- `MediaStationGo-1.2.1-windows-x64-source.zip`：对应发布候选提交的完整源码包。
- `SHA256SUMS.txt`：上述三个包的 SHA-256 校验值。

安装版和便携版均支持在“设置 → 更新”中检查、下载并应用新版本。本次通过 GitHub Releases 分发，不启用旧 CDN；已有可选视频增强组件继续复用，无需重复下载。普通播放不要求 NVIDIA 显卡或安装 NVIDIA 增强组件。

## 验证与边界

发布前执行相关 Rust 单测、离线界面回归、剪贴板边界测试及候选包校验。测试使用离线桥接样例和本地 loopback 服务，不进行真实云盘或 115 批量探测，也不修改用户账号和剪贴板。

标准 HTTP 首次响应复用的既有本地 libmpv 对照见[播放诊断记录](https://github.com/timefunnel/MediaStationGo-Windows/blob/v1.2.1/docs/windows-playback-diagnostics.md)：该结果用于验证去掉重复请求，不代表所有远端影片的固定提速幅度。窗口恢复的实测范围与长期观察边界见[窗口尺寸同步记录](https://github.com/timefunnel/MediaStationGo-Windows/blob/v1.2.1/docs/windows-window-geometry.md)。本次不将历史短时测试视为跨设备、长时间后台恢复或所有真实片源的完整验收。
